# Profile panel setup

The profile README is a stack of six SVG panels in `assets/`, all 1200px wide and sharing one harbour-at-night style (navy, lamp gold).

| Panel | Built by | Data |
| --- | --- | --- |
| `hero.svg`, `stack.svg`, `activity.svg` | `scripts/build-panels-a.mjs` writes `templates/*.svg.tpl`; `scripts/generate.mjs` fills them | Live: repo count, account start, language shares, weekly contributions |
| `about.svg`, `projects.svg`, `footer.svg` | `scripts/build-panels-b.mjs` writes the final SVGs directly | None (static text) |

`forest-temple.svg` (the older banner) is still generated by `generate.mjs` from `templates/forest-temple.svg.tpl`, which comes from `scripts/build-template.mjs`.

## Pipeline

1. Art: edit `scripts/build-panels-a.mjs` or `scripts/build-panels-b.mjs`.
2. Static panels: `node scripts/build-panels-b.mjs` (no token needed).
3. Live panels: `GITHUB_TOKEN=$(gh auth token) node scripts/generate.mjs` reads the templates, fetches aggregates from the GitHub API and writes `assets/*.svg`. Only counts, dates and shares are written, never repo names.

Panels must stay safe for GitHub's `<img>` rendering: no `<script>`, no external assets, no links inside the SVG (links live in README markdown), CSS/SMIL animation only, and a `prefers-reduced-motion` block.

## Daily refresh (GitHub Actions)

`.github/workflows/refresh.yml` runs daily and on demand, regenerates the panels and commits `assets` and `forest-temple.svg` only if they changed.

1. Create a token that can read your repos and contribution data (private ones included, if you want them counted).
2. Add it as a repository secret named `PROFILE_TOKEN`.
3. Run the "Refresh banner" workflow once from the Actions tab.

## Activity panel fallback

`activity.svg` shows a "Harbour log" fallback instead of the tide chart until the account setting "Include private contributions on my profile" is on and the contribution total reaches the threshold (set to 50 in `generate.mjs`). Turn the setting on in your GitHub profile settings, then re-run the workflow.

# Banner setup

The banner `forest-temple.svg` is generated by `scripts/generate.mjs` (Node 20, no dependencies) from `templates/forest-temple.svg.tpl`.

It shows aggregates only: repo count, years active (from the account creation date) and language shares. Repo names are never written.

Art lives in scripts/build-template.mjs → templates/forest-temple.svg.tpl → scripts/generate.mjs.

## Refresh locally

    GITHUB_TOKEN=$(gh auth token) node scripts/generate.mjs

## Daily refresh (GitHub Actions)

`.github/workflows/refresh.yml` runs daily and on demand, regenerates the SVG and commits it only if it changed.

1. Create a token that can read your repos (private ones included, if you want them counted).
2. Add it as a repository secret named `PROFILE_TOKEN`.
3. Run the "Refresh banner" workflow once from the Actions tab.
